### Инструкция как получить API-ключ

Чтобы получить API ключ для Groq, нужно зарегистрироваться в Groq Cloud, войти в свою учетную запись, перейти в раздел API ключей и создать новый ключ. После генерации ключ нужно скопировать и сохранить в безопасном месте, рекомендуется также настроить его как переменную среды, чтобы избежать случайного раскрытия. 

**Подробная инструкция:**

1. Зарегистрироваться и войти в Groq Cloud:

    Перейдите на сайт Groq Cloud (https://console.groq.com/) и создайте аккаунт, если у вас его еще нет. Затем войдите в свою учетную запись. 

2. Перейти в раздел API ключей:

    После входа в систему найдите раздел "API Keys" (Ключи API) на панели навигации слева. 

3. Создать новый ключ:

    Нажмите на кнопку "Create API Key" (Создать ключ API). 

4. Заполнить информацию о ключе:

    В появившемся окне укажите имя ключа, чтобы его можно было легко идентифицировать в будущем. 

5. Сгенерировать ключ:

    Нажмите кнопку "Submit" или "Create" для создания ключа. 

6. Скопировать и сохранить ключ:

    После генерации ключ будет отображен на экране. Скопируйте его и сохраните в надежном месте, так как вы не сможете получить доступ к нему снова после закрытия страницы. 

7. Рекомендуется настроить ключ как переменную среды:

    Для повышения безопасности и удобства рекомендуется настроить ключ как переменную среды, чтобы не включать его непосредственно в код.
